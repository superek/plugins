# superek-plugins

Claude Code 개인 플러그인 마켓플레이스.

## loop

문제를 풀고, 그 문제를 내 것으로 만드는 4개 스킬.

```
증상이 있다        →  /loop:trace           원인 찾기
고쳤다             →  /loop:review          검증하기
놀랐다             →  /loop:retro           교훈 굳히기
교훈이 규칙이 됐다  →  /loop:skill-standard  어디에 어떻게 저장할지
```

앞의 둘은 **코드에** 하는 일이고, 뒤의 둘은 **나에게** 하는 일이다.
앞의 둘은 안 하면 버그가 남지만, 뒤의 둘은 안 해도 오늘은 아무 일도 안 생긴다 — 그래서 항상 이쪽부터 빠진다.

### `/loop:trace` — 증상에서 원인으로

층 가르기(데이터·표시·배선) → 되는 것과의 차이 → 싼 프로브 → 관측 신뢰도 검사 → 원인 확정.

- **선언된 값이 아니라 실제 주입된 값**을 먼저 본다
- 결과가 안 갈리면 실행을 반복하지 말고 **명세를 연다**
- 로컬에서 본 값으로 단정하기 전 5단 확인(프로세스 최신성·목·시드 비율·분포·계약)

### `/loop:review` — 변경에서 결함으로

기준(base) 확정 → 규모 판정 → 기계적 검사 → 스펙 확보 → 다축 렌즈 → 적대적 재검증 → 원인 묶기 → 리포트 → 이해도 퀴즈.

- **base를 추측하지 않는다.** 틀려도 `git diff`는 성공하기 때문에 조용히 엉뚱한 범위를 본다
- **코드 사실과 화면 사실을 가른다.** "이 줄이 이렇게 쓰여 있다"와 "그래서 화면에 이렇게 보인다"는 다른 확정이다
- **구분력 없는 관측은 증거가 아니다.** 반대 가설에서도 같은 값이 나오면 아무것도 증명 못 한 것
- **묶임은 관측이 끝난 뒤에 묻는다.** 조치가 "세 곳 고쳐라"에서 "하나 고쳐라"로 바뀐다
- 심각도와 **수정 주체**(자동/사람)를 따로 매긴다 — 두 축은 직교한다

기계적 검사 명령어와 수정 안전 루프는 [`skills/review/checks.md`](plugins/loop/skills/review/checks.md).

### `/loop:retro` — 사건에서 교훈으로

사건 3줄 → 근본 원인 → **재발 신호** → 규칙 1개 → 저장 위치 판정.

- 회고 문서가 안 읽히는 이유는 내용이 나빠서가 아니라 **언제 꺼낼지 몰라서**다. 재발 신호가 그 자리를 메운다
- 새 파일보다 **기존 파일 흡수**가 먼저
- **원리는 안 낡고 상태는 낡는다.** 낡을 수 있는 사실엔 재확인 방법을 같이 적는다

### `/loop:skill-standard` — 교훈에서 형식으로

저장 위치 판정 → frontmatter 규칙 → 필수 섹션 → 근거 링크 → 결정적/판단 분리 → 멈추는 지점.

- `description`은 내용 요약이 아니라 **트리거 목록**이다
- **금지 섹션을 못 쓰겠으면 아직 이해가 덜 된 것**이다
- 좁은 곳에서 넓은 곳으로 올릴 땐 경로·브랜치명·포트 같은 **고유값을 벗긴다**

## 설치

```bash
claude plugin marketplace add superek/plugins
```

```bash
claude plugin install loop@superek
```

설치 후 세션을 새로 열어야 스킬이 잡힌다.

> 마켓플레이스 이름(`superek`)은 레포 이름이 아니라 `.claude-plugin/marketplace.json` 의 `name` 필드에서 온다.

로컬 경로로도 추가할 수 있다 — 원격에 올리기 전에 시험할 때.

```bash
claude plugin marketplace add ~/Desktop/work/superek-plugins
```

## 설계 원칙

이 스킬들은 다른 플러그인을 복사한 것이 아니라, 실제 작업에서 나온 오판 기록을 근거로 다시 쓴 것이다.
각 규칙 옆의 괄호는 그 규칙이 나온 사건을 가리킨다.

- **절차는 여기, 고유값은 로컬 설정으로.** 프로젝트 키·브랜치 규칙·리뷰어 이름은 이 레포에 넣지 않는다
- **SKILL.md는 150줄 이하.** 넘치면 자르지 말고 옆 파일로 뺀다
- **애매하면 멈춘다.** 확정 못 한 값을 기본값으로 조용히 채우지 않는다
